SupportNotifier unit contracts
==============================

From the repository root, using Node.js 22 or newer:

    node --test tests/support-notifier.test.mjs

To retain raw V8 coverage outside the checkout:

    coverage_dir="$(mktemp -d)"
    NODE_V8_COVERAGE="$coverage_dir" node --test --experimental-test-coverage \
        --test-coverage-include='**/src/lib/SupportNotifier.js' \
        tests/support-notifier.test.mjs

The suite imports the unchanged SupportNotifier module. Settings defaults come
from the real schema; doubles check settings keys, timer ownership, signal
cleanup, fullscreen deferral, release suppression and notification actions.
Version parameters exercise the pre-46 and 46+ notification API contracts.

These are offline unit tests, not GNOME Shell integration or end-to-end tests.
They do not establish actual Shell compatibility, launch a browser, open
preferences or display notifications. No dependencies or shared runner
configuration are required.
